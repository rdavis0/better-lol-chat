# better-lol-chat

Unofficial Pengu Loader plugin that improves League of Legends **post-game chat**. Not endorsed by Riot Games. Do not inject ads into the League client.

## Feature list

Living checklist (shipped + planned): [`docs/FEATURE_LIST.md`](docs/FEATURE_LIST.md)

Planned next (not built yet): toggle **champion names ↔ player names**.

## Install

Plugin source: `pengu-plugin/better-postgame-chat/`

Copy into:

```text
C:\Program Files\Pengu Loader\plugins\better-postgame-chat
```

Restart League (Pengu active). Console should show `[better-postgame-chat]`.
